Assessment flow

From a rubric file to a shareable record.

  1. Load a rubric

    In the checker, choose Import Rubric JSON to select a saved file, or use Paste JSON. The built-in rubric is ready in the library. You can also inspect the sample rubric JSON.

  2. Start and mark evidence

    Select a rubric, enter the student's name, then click an item to cycle its status. Items move through blank, complete, almost, not done, and back to blank.

    BlankCompleteAlmostNot Done

  3. Find the right view

    Focus Mode narrows the rubric to one band. If the rubric has tags, Tag Mode filters items by tag. Use the Comments button on the view bar to open or collapse the assessment comments box.

  4. Copy or export your assessment

    Use Copy for Google Docs and paste with Cmd+V on Mac. Export Markdown opens copyable Markdown with an optional download. Export JSON saves the student's statuses and comments; use Load completed JSON later to reopen that assessment.

  5. Edit a rubric

    From the rubric library, choose Edit JSON to change a rubric, validate and save it, or export the edited JSON. Saved rubrics stay in this browser's local storage.

Local by design. Rubric library changes are stored in this browser on this device. Export completed JSON when you need a portable copy or want to continue the assessment elsewhere.
